Entry for the make.fun bounty **One-Line Laugh-Off** ($2, winner-takes-all, free entry).

The program writes exactly one funny line to `/output/entry.txt`:

> I told my AI not to lie; it said, 'Then stop asking me to write your dating profile.'

Run locally with `MAKEFUN_OUTPUT_DIR=/tmp/laugh-test python3 main.py`.
